# Kurs: Приложение "Автосалон" 🚗💰

Это учебное Android-приложение для покупки и продажи автомобилей, написанное на **Java** с использованием **SQLite**. В приложении реализована полноценная система экономики, личного профиля и управления объявлениями.

## ✨ Основные функции

*   **Лента объявлений**: Просмотр всех доступных автомобилей от разных авторов.
*   **Детальная информация**: Экран с полным описанием, характеристиками, рейтингом и фото автомобиля.
*   **Система экономики**: 
    *   У каждого пользователя есть баланс (начальный капитал 10 000 000 руб.).
    *   Возможность покупки авто: деньги списываются, а машина переходит в статус доставки.
    *   Тестовая кнопка в профиле для пополнения баланса (+1 млн руб.).
*   **Личный профиль**:
    *   Управление своими объявлениями (добавление, редактирование, удаление).
    *   Раздел купленных машин со статусом **"В доставке"**.
    *   Подтверждение получения товара.
*   **Добавление объявлений**:
    *   Загрузка реальных фото из галереи телефона.
    *   Валидация данных (например, описание не менее 10 символов).
    *   Автоматическая подстановка автора.

## 🛠 Технологии

*   **Язык**: Java
*   **База данных**: SQLite (хранение машин, баланса и истории покупок)
*   **UI**: Material Design, RecyclerView, CardView, Relative/Linear Layouts
*   **Работа с фото**: Android Storage Access Framework (URI-based image loading)
